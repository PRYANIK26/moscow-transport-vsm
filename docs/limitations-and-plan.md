# Ограничения и развитие

## Текущие ограничения

- Регистрация без подтверждения email; восстановление пароля не подключено.
- Голос и ИИ-помощник требуют ключей Яндекса; Web Push — VAPID и разрешения браузера.
- Мобильное прохождение проверено в Chromium с эмуляцией touch. Физические Android/iOS, микрофоны и доставка уведомлений ОС требуют отдельной проверки.
- Сложные предметные ситуации пока используют доступные модели и действия. Отдельных полноценных механик для кошки, коляски и передачи ребёнка нет.
- Некорректный JSON-импорт может оставить пустой черновик. Повторная публикация без изменения создаёт новую версию.
- Баллы и учебные тексты не являются утверждённой системой аттестации. Нужна проверка профильным специалистом.
- Архитектура допускает несколько API и worker; длительный нагрузочный тест и эксплуатационные SLO не проводились.
- Часть старых браузерных тестов относится к предыдущей навигации; актуальные игровые пути проверялись отдельно.

## После хакатона

1. Закрыть дефекты импорта и повторной публикации; обновить браузерные регрессионные тесты.
2. Проверить сценарии и оценку общения с инструкторами; добавить рабочее место проверки спорных результатов.
3. Провести испытания на Android/iOS, улучшить производительность и управление 3D.
4. Подключить подтверждение email, восстановление пароля и корпоративный вход.
5. Настроить мониторинг, резервное копирование с проверкой восстановления и нагрузочные испытания нескольких API/worker.
6. Расширить библиотеку моделей и действий, затем подключить согласованные HR/LMS-интеграции.
